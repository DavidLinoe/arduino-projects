# arduino-projects
  Este repositório reúne projetos práticos de eletrônica, robótica e sistemas embarcados com Arduino, simulações no Tinkercad e programação em C++.   O acervo cobre desde experimentos introdutórios até projetos aplicados em automação, sensoriamento e controle de motores, refletindo a evolução técnica ao longo de anos de prática contínua.
